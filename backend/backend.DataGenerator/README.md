# backend.DataGenerator

Console utility to generate and clean demo data for the Halcon database.

## What it does

- `seed`: inserts demo orders and (optionally) profile rows based on existing `auth.users` records.
- `cleanup`: removes only rows generated by this tool.

## Safety model

- Orders are tagged with a deterministic marker:
  - `invoice_number` starts with `DEMO-INV-`
  - `notes` contains `[DEMO-GENERATED]`
- Profiles generated by this tool use `username` prefix `demo_user_`.
- Cleanup removes only rows that match those markers.

## Where to use

This tool is intended to be used as a GitHub Action.

## Connection string

The tool requires the following GitHub Secret:
- MIGRATIONS_DB_CONNECTION

## Usage

```bash
dotnet run --project backend/backend.DataGenerator/backend.DataGenerator.csproj -- seed --orders 300 --profiles 25
```

```bash
dotnet run --project backend/backend.DataGenerator/backend.DataGenerator.csproj -- cleanup
```

## Notes about profiles

`public.profiles.auth_user_id` has a foreign key to `auth.users(id)`. For this reason, the generator never invents random auth IDs. It only inserts profile rows for `auth.users` entries that still do not have a profile.
